# Comfort Verses — For Hard Nights

A quiet, mobile-friendly page of comfort Scriptures for hard nights — for anyone anxious, grieving, afraid, or sleepless.

Verses are grouped by need:

- **Anxiety** — 1 Peter 5:7, Isaiah 41:10, Philippians 4:6–7
- **Fear** — Psalm 23:4, Psalm 56:3, 2 Timothy 1:7
- **Grief** — Psalm 34:18, Matthew 5:4, Revelation 21:4
- **Sleeplessness** — Psalm 4:8, Psalm 121:3–4, Matthew 11:28

Scripture quotations are from the World English Bible, a public-domain translation.
